# Boots — Public Documentation

This repository is the public documentation for **Boots**, the Discord bot serving the **CUSA** community (Clockwork's United States Army — a Roblox military roleplay group: https://www.roblox.com/communities/4219097).

## What's here

| Path | Purpose |
|---|---|
| `PRIVACY.md` | Privacy policy — what data Boots collects, how it is used, stored, encrypted, and deleted |
| `TERMS.md` | Terms of service for using the bot and the community |
| `knowledge/` | The public knowledge base the bot uses to answer questions about CUSA |

### Knowledge base layout

- `knowledge/MAIN.md` — entry point: about CUSA, owners, and how to use the knowledge base
- `knowledge/teams/` — ownership and development team information
- `knowledge/operations/` — divisions, formations, and training requirements
- `knowledge/reference/` — FAQs, support channels, and reference terms
- `knowledge/external_sources.json` — index of live external reference documents

## How updates work

This repo is the source of truth for the published docs. Changes pushed to `main` are picked up automatically and go live without a manual deploy. To update the docs, edit the files in this repo and push to `main`.
